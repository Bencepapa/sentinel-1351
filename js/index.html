Verification log

The unchanged 8502 binaries from c128-gui/cockpit, c128-map and c128-flight run on a JS 6502 core. Their VIC-IIe, VDC, SID, CIA and 1351 registers are handled by JS; the VIC screen is drawn line by line from the register writes logged at each raster position, so raster splits show as on the real chip. Routines are hooked by label from the assembler's symbol table; PLOTPIX, ERASEPIX and MOVCHK have JS ports that run beside the originals and are compared on every call.

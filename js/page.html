The unchanged binaries run on a JS 6502 core: the patched C64 game (Sentinel-1351_v8.prg) and the native C128 programs from c128-gui/cockpit, c128-map and c128-flight. The VIC is drawn line by line from the register writes logged at each raster position. Labels come from the assemblers' symbol tables and, for the C64 game, from js/c64-symbols.txt. Save states are kept in this browser.
